# Art direction

User-provided visual reference: https://x.com/9ura00/status/2109747013931921843

The reference video was inspected during production. It shows small, low-poly outdoor objects with believable real-world construction and subdued materials.

## Applied direction

- Realistic proportions and immediately recognizable silhouettes.
- Muted industrial colors, timber tones, galvanized steel and restrained safety colors.
- Deliberate functional details: rims, handles, hinges, rails, trim, grilles, fasteners and mechanisms.
- Economical geometry and visible faceting, without voxel blocks or exaggerated toy proportions.
- Narrow one-segment edge chamfers when the exported vertex budget permits.
- Solid-color shared materials rather than texture-heavy surfaces.
- American city object selection and signage; the reference supplies the visual direction, not a catalog to copy.

The reference creator's video and models are not included. The mesh source in this repository is newly authored procedural geometry.

## Preview interpretation

Catalog thumbnails are generated from the actual exported GLB triangles with orthographic software shading. Objects are framed individually, so their apparent sizes in the catalog are not comparable. The master Blender overview uses collection instances; the original meshes remain at world zero.
